# ARMA — планировщик тренировок по BJJ для Android

**ARMA** — Android-приложение для планирования и учёта тренировок по бразильскому джиу-джитсу (BJJ).

## Возможности

- Планирование и организация тренировок по BJJ.
- Просмотр расписания тренировок.
- Ведение истории тренировок.
- Резервное копирование и восстановление данных о тренировках.

## Скачать

Скачать последнюю версию APK для Android можно на странице [GitHub Releases](https://github.com/956x7jh9ft-hue/ARMA-Android/releases).

**Текущая версия:** `1.0.0-beta.1` — предварительная версия для тестирования.

### Установка

1. Скачайте APK из раздела с файлами релиза.
2. Откройте загруженный APK на Android-устройстве.
3. Если Android запросит разрешение, разрешите установку приложений из этого источника.
4. Следуйте инструкциям на экране.

Устанавливайте APK только из этого репозитория и проверяйте, что публикация действительно принадлежит владельцу проекта.

## Данные и резервные копии

Создавайте резервную копию данных о тренировках перед выполнением любых действий, которые могут повлиять на сохранённые данные приложения. Храните резервные копии в безопасном месте и не публикуйте их в открытом доступе.

## Статус проекта

ARMA находится в активной разработке. Функциональность и поведение приложения могут меняться в последующих бета-версиях.
